# Get HA Recipe Manager

Diese einmalig ausgefuehrte App installiert oder aktualisiert die Home-Assistant-Integration **HA Recipe Manager**.

## Installation

1. Installiere diese App.
2. Waehle **Starten**.
3. Oeffne das Protokoll und warte auf die Meldung, dass die Installation erfolgreich war.
4. Starte Home Assistant neu.
5. Oeffne **Einstellungen > Geraete & Dienste**.
6. Waehle **Integration hinzufuegen** und suche nach **HA Recipe Manager**.

Die Home-Assistant-Integration **Einkaufsliste** muss ebenfalls eingerichtet sein.

## Aktualisierung

Wenn im App Store eine neue Version angeboten wird, aktualisiere diese App und starte sie danach einmal. Anschliessend ist ein Neustart von Home Assistant erforderlich.

Die gespeicherten Rezepte liegen in Home Assistant `.storage` und werden bei einer Aktualisierung der Integration nicht geloescht.
